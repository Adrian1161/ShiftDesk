
# User Stories

## Story 1 (Essential):
I as an Owner want to be able to register my business and invite employees so that my team can use ShiftDesk.

### Acceptance Criteria:
Business is registered successfully, and the Owner is able to invite employees to join the business.

## Story 2 (Error Handling):
I as an Employee want to be denied access to another business's data and manager-only pages so that information stays private.

### Acceptance Criteria:
When an Employee attempts to access another business's data or a manager-only page without permission, access is denied.

## Story 3 (Essential):
I as an Employee want to be able to enter my weekly availability so that I am scheduled when I can work.

### Acceptance Criteria:
Employee is able to enter and save their weekly availability successfully.

## Story 4 (Essential):
I as a Manager want to be able to create and assign shifts for a week so that every position is covered.

### Acceptance Criteria:
Manager is able to create shifts for a selected week and assign employees to those shifts.

## Story 5 (Error Handling):
I as a Manager want to be stopped from assigning overlapping shifts to one employee so that the schedule is valid.

### Acceptance Criteria:
When a Manager attempts to assign overlapping shifts to the same Employee, the system prevents the assignment and displays an error message.

## Story 6 (Essential):
I as a Manager want to be able to publish a week's schedule so that employees can see it.

### Acceptance Criteria:
Manager is able to publish a weekly schedule, and Employees are able to view the published schedule.

## Story 7 (Essential):
I as an Employee want to be able to see my upcoming shifts so that I know when to work.

### Acceptance Criteria:
Employee is able to view their upcoming shifts, including the dates and times they are scheduled to work.

## Story 8 (Essential):
I as an Employee want to be able to offer a shift for a coworker to take, subject to manager approval, so that I can handle conflicts.

### Acceptance Criteria:
Employee is able to offer an assigned shift to a coworker, and the shift swap requires Manager approval before it is finalized.

## Story 9 (Error Handling):
I as an Employee want a clear error to be displayed if my time-off dates are invalid so that I can fix them.

### Acceptance Criteria:
When an Employee enters a time-off request with an end date before the start date or a date in the past, an error message is displayed and the invalid request is not submitted.

## Story 10 (Stretch):
I as an Owner want to be able to view a weekly labor-hours summary so that I can control costs.

### Acceptance Criteria:
Owner is able to view a summary of the total labor hours scheduled for a selected week.
