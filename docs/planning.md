# Project Name: ShiftDesk

## 1. Overview
- **Objective:** Build a scheduling/shift management application for small hourly-staff businesses.
- **Target Audience:** Managers who need a fast and intuitive way to build weekly schedules.  Employees that need easy access to their upcoming shifts, ability to swap shifts easily with other employees, and easily request time off.

## 2. Tech Stack
- **Backend & Frontend:** Ruby on Rails
- **Database:** PostgreSQL
